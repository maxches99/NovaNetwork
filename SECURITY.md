# Security Policy

## Supported Versions

Security fixes are provided for the latest release line.

| Version | Supported |
| ------- | --------- |
| latest  | Yes       |
| older   | No        |

## Reporting a Vulnerability

Please do not open public GitHub issues for security vulnerabilities.

To report a vulnerability, contact the maintainer directly via GitHub profile:
https://github.com/maxches99

Please include:

- A clear description of the issue and affected component.
- Steps to reproduce or a proof of concept.
- Potential impact.
- Suggested remediation (if available).

## Response Process

- Initial acknowledgement target: within 72 hours.
- Triage and severity assessment: as quickly as possible.
- Fix and release timeline: depends on severity and complexity.

We will coordinate disclosure details with the reporter and publish a fix note when a patch is released.
